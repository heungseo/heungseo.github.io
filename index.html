박흥서의 포트폴리오

자기소개

안녕하세요! 경기도 양주에 거주하는 인공지능학과 **박흥서**입니다. 데이터 분석과 웹 개발 분야에 큰 관심을 가지고 있으며, 파이썬(Python)과 판다스(Pandas)를 활용한 데이터 분석 프로젝트 경험이 있습니다.

또한, HTML/CSS/자바스크립트(JavaScript)를 이용하여 웹 페이지를 제작해보는 등 실무 경험을 쌓기 위해 노력하고 있습니다.
아직 부족한 점이 많지만, 성실함과 꾸준한 노력으로 끊임없이 성장하는 개발자가 되고 싶습니다.

💻 프로젝트 경험

1. 데이터 전처리 및 분석 프로젝트

파이썬(Python)과 판다스(Pandas) 라이브러리를 깊이 있게 활용하여 날것의 데이터에서 결측치와 이상치를 탐지하고 정제했습니다. 머신러닝 모델이 더 잘 학습할 수 있도록 범주형 데이터를 수치화(인코딩)하고, 데이터의 스케일을 맞추는 등 분석의 기초가 되는 탄탄한 전처리 역량을 길렀습니다.

2. 깃허브 포트폴리오 웹사이트

GitHub Pages의 정적 웹 호스팅 기능을 활용하여, 저의 학습 기록과 프로젝트를 보여줄 수 있는 포트폴리오 사이트를 직접 구축하고 배포했습니다. 이 과정을 통해 Git을 통한 버전 관리와 웹 배포의 기본 흐름을 실습했습니다.

3. 딥러닝 기초 학습 프로젝트

인공지능의 핵심인 딥러닝의 작동 원리를 이해하기 위해 시작한 프로젝트입니다. 기초적인 신경망(Neural Networks) 구조를 공부하고, 딥러닝 프레임워크를 활용하여 간단한 모델을 직접 구현 및 학습시켜보며 AI 분야의 전문성을 쌓기 위한 첫걸음을 내디뎠습니다.

🌱 학습 중인 기술 (Skills & Study)

Programming Languages & Web Basics

전공 기초 과목과 독학을 통해 문법과 기본 개념을 충실히 익히는 단계입니다.

  • Python: 기초 문법을 공부하고, 데이터 분석 라이브러리 활용 예제를 따라 해보는 학습 단계
  • Java: 변수, 제어문 등 프로그래밍 기초와 객체지향의 기본 개념을 수업을 통해 이해하는 과정
  • HTML/CSS/JavaScript: 웹이 어떻게 동작하는지 기본 원리를 배우고, 간단한 화면을 직접 만들어보며 기초를 다지는 중

Tools

효율적인 학습을 위해 기본적인 도구 사용법을 익혀나가고 있습니다.

  • Git/GitHub: 코드 저장과 버전 관리의 필요성을 배우고, add, commit, push 등 기초 명령어 사용을 연습하는 중
  • VS Code: 주로 사용하는 학습용 코드 에디터
